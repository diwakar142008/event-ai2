# Credits and provenance

## Art direction

**The Editorial Event Atelier** is an original direction developed for this project. It combines editorial serif display type, asymmetric compositions, fine rules, restrained colour blocks, and a dark analytics surface. No reference site's layout, source code, brand, or proprietary assets were copied, and no site was scraped.

The written brief referenced contemporary editorial galleries (httpster.net, recent.design, dark.design, nicelydone.club, minimal.gallery) as inspiration only. The implementation follows the documented design direction and the palette specified in the brief.
